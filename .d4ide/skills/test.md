# Test Runner & Fixer Skill

Run the project automated test suite, diagnose failures, and repair broken code.

Workflow:
1. Run `pnpm test` or `npm test`.
2. Parse any error outputs, stack traces, and failing assertions.
3. Locate the corresponding source or test files.
4. Apply minimal targeted fixes.
5. Re-run tests to confirm all suites pass with 0 errors.
