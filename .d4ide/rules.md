# D4IDE Project Rules

- Use TypeScript with strict type-checking enabled.
- Avoid using `any` types; prefer explicit interfaces and type unions.
- Follow the D4 Dark UI theme and clean component separation.
- Never hardcode API keys or secrets in source files or localStorage.
- Run tests (`pnpm test` or `npm test`) and build verification before concluding tasks.
- Keep agent timeline outputs clear and concise without raw chain-of-thought noise.
